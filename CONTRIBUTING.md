# Contributing

Requires Node.js 20+ and pnpm 11.

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
```

Keep site specifications free of secrets and personal data. Add deterministic tests for runtime behavior. Consequential discovery actions must never run without explicit user authorization. Use Conventional Commits for changes.

User-facing documentation must present agent conversation as primary interface. Runtime CLI is internal infrastructure, not expected user workflow.
